# 🎮 Street Fighter 6 - Custom Character Select UI

![UI Showcase - Jamie & Dee Jay](https://via.placeholder.com/1200x400.png?text=Street+Fighter+6+UI+Redesign)

## 📌 Project Overview
This repository showcases a **Custom UI/UX Redesign** for the **Street Fighter 6** character selection and stats screen. The design focuses on a clean, modern, and highly visual aesthetic, featuring a dynamic grid layout, character bios, and key combat statistics. 

The project goes beyond just UI design by integrating a complete **Character Database** containing stats and lore for all 20 fighters in the roster.

## ✨ Key Features
- **High-Fidelity Dashboard:** A sleek, dark-themed interface with vibrant, character-specific accent backgrounds (like Jamie's martial arts aura and Dee Jay's paint splatters).
- **Interactive Layout Concept:** Grid-based character selector on the right, balanced with full-body character portraits and detailed stats on the left.
- **Comprehensive Database:** Powered by an Excel dataset (`Street Fightercharacters_stats.xlsx`) detailing 20 diverse characters.

## 📊 Dataset Insights
The included dataset contains in-depth combat statistics and lore for **20 Characters**, ensuring the UI is populated with accurate game data. 

**Roster Breakdown:**
- **Total Fighters:** 20 (Ryu, Luke, Jamie, Chun-Li, Guile, Kimberly, Juri, Ken, Blanka, Dhalsim, E. Honda, Dee Jay, Manon, Marisa, JP, Zangief, Lily, Cammy, Rashid, A.K.I.)
- **Combat Types:** Speed (6), Tricky (5), Power (5), Standard (4)
- **Effective Ranges:** Mid-Range (12), Long-Range (4), Close-Range (4)
- **Ease of Use:** Normal (12), Hard (6), Easy (2)

*Data fields include: Vitality, Type, Effective Range, Ease of Use, Bio, Hates, Likes, Height, Weight, and Image URLs.*

## 🛠️ Tools & Tech Stack
- **UI/UX Design:** Figma / Canva / Photoshop (for layout, typography, and visual hierarchy)
- **Data Management:** Microsoft Excel / Pandas (for managing character stats and metrics)
